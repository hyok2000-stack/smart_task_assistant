看板口径
红黄绿判定红色：扣分/延期/未完成/质量问题；黄色：暂停/暂缓/待确认/有计划无实际；绿色：已完成或按计划推进。
统计①
总体结论栏（各月合并）以下统计基于全部月份合并分析，不随月份切换变化：
• 任务总数：工作表中所有有效任务的数量
• 正常：任一月份曾判定为绿色（实际进展含"已完成/完成/已上线/已部署/已发起/已提交/已输出"等关键词）
• 风险：从未判定为红色，也从未判定为绿色的任务
• 异常：任一月份曾判定为红色（扣分/延期/未完成/质量问题）
• 按期完成率 = 曾为绿色的任务数 ÷ 任务总数 × 100%
• 问题闭环率 = 任一月份曾闭环的任务数 ÷ 任务总数 × 100%（闭环 = 状态绿色 或 实际含完成关键词）
• 需盯办：任一月份曾为红色 或 需要协调的事项
• 完成：任一月份的实际进展中包含"已完成/完成/已上线/已部署/已发起/已提交/已输出"等关键词的任务数
• 暂停：任一月份的实际进展中包含"暂停/暂缓"关键词的任务数
统计②
决策区（按选中月份）以下统计随月份切换动态变化：
• 需领导盯办：选中月份判定为红色 或 含"协调"关键词且非绿色的任务
• 重点任务：keyTask 列包含"重点任务"的任务
• N月有计划：选中月份计划列有内容，或阶段性成果计划中提到该月份
• 自研任务：是否自研列包含"是"的任务
• 完成任务：选中月份的实际进展中包含完成关键词的任务
• 暂停任务：选中月份的实际进展中包含"暂停/暂缓"的任务
统计③
分类判定规则按选中月份的数据逐一判定，优先级从高到低：
① 红色：得分 < 0 或 含"扣分/未按要求/质量问题" → 扣分/质量问题
② 红色：含"延期/延时/未完成" → 当月延期或未完成
③ 黄色：有计划但未填实际 → 当月有计划但未填实际
④ 黄色：含"暂缓/暂停/待确认/未开始/暂未启动/暂无进度/跟进/正在/待/风险" → 暂停/待确认/外部依赖
⑤ 绿色：实际含"已完成/完成/已上线/已部署/已发起/已提交/已输出" → 已完成或按计划推进
⑥ 黄色：以上均不匹配 → 进展待补充
