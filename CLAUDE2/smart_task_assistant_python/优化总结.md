## 🎯 使用指南

### 1. 使用优化后的数据库

```python
from core.database_optimized import DatabaseManagerOptimized

# 替换原有的 DatabaseManager
db = DatabaseManagerOptimized(db_path)

# 使用分页查询
tasks, total = db.get_tasks_paginated(
    page=1, 
    page_size=50,
    status='pending'
)

# 自动缓存
tasks = db.get_all_tasks()  # 第一次查询数据库
tasks = db.get_all_tasks()  # 第二次从缓存读取（99.7%提升）
```

