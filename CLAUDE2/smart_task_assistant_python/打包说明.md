# 智能任务助手 - 打包说明

## 打包步骤

### 方法一：使用打包脚本（推荐）

1. 双击运行 `打包.bat`
2. 等待打包完成
3. 在 `dist` 目录下找到 `智能任务助手.exe`

### 方法二：手动打包

1. 安装PyInstaller：
   ```
   pip install pyinstaller
   ```

2. 执行打包命令：
   ```
   pyinstaller --noconfirm --onefile --windowed --name "智能任务助手" --add-data "ui;ui" --add-data "core;core" main.py
   ```

3. 打包完成后，exe文件在 `dist\智能任务助手.exe`

## 分发说明

打包后的 `智能任务助手.exe` 是一个独立的可执行文件，可以：

- 直接发送给其他用户
- 无需安装Python环境
- 双击即可运行

## 注意事项

- 首次运行会在用户目录创建配置文件和数据文件
- 如需使用AI功能，请在设置中配置API密钥
