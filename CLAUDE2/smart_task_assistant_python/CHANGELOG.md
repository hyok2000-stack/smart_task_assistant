## [1.0.0] - 2026-03-05

### 新增功能
- **任务管理**
  - 创建、编辑、删除任务
  - 任务状态管理（待处理、进行中、已完成、已取消）
  - 任务优先级设置（高、中、低）
  - 任务截止时间设置
  - 任务负责人分配
  - 任务标签管理
  
- **智能识别**
  - 本地 AI 模型集成
  - 自然语言任务识别
  - 自动提取截止时间
  - 自动提取负责人
  - 自动识别优先级
  - 自动生成验收标准
  
- **提醒系统**
  - 多时间点提醒（30 分钟、1 小时、1 天、3 天等）
  - 系统托盘通知
  - 图标闪烁提醒
  - 错过时间后的持续提醒
  - 每 5 分钟重复提醒
  
- **周期任务**
  - 支持每日重复
  - 支持每周重复
  - 支持每月重复
  - 自动创建下一个周期任务
  
- **数据管理**
  - SQLite 数据库存储
  - JSON 格式导出
  - Excel 格式导出
  - 数据备份功能
  - 数据恢复功能
  
- **用户界面**
  - 系统托盘集成
  - 右键菜单操作
  - 任务筛选（状态、优先级、负责人、时间）
  - 任务搜索
  - 统计界面
  - 智能建议界面
  
- **剪贴板监听**
  - 自动检测剪贴板内容
  - 智能识别任务信息
  - 一键创建任务

### 技术特性
- Python 3.12
- PyQt5 GUI 框架
- SQLite 数据库
- 本地 AI 模型支持
- 跨平台支持（Windows、Linux、macOS）

### 版本号规则
- **主版本号**: 重大架构变更或不兼容的 API 修改

- **修订号**: 向后兼容的问题修复

### 发布周期
- **主版本**: 每 6 个月
- **次版本**: 每 1-2 个月
- **修订版**: 按需发布
