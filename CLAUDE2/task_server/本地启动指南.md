# 智能任务中心后台服务 - 本地启动指南

## 📋 概述

本指南提供了完全本地化的后台服务启动方案，**无需安装 Docker、PostgreSQL 和 Redis**，直接使用 SQLite 数据库运行。

### 🎯 本地化方案优势

- ✅ **零依赖**：无需安装 Docker、PostgreSQL、Redis
- ✅ **快速启动**：一键启动，无需等待容器构建
- ✅ **易于调试**：直接运行，方便查看日志和调试
- ✅ **资源占用低**：只运行一个 Go 进程，占用资源少
- ✅ **数据库简单**：使用 SQLite，数据库文件存储在本地
- ✅ **适合开发**：开发环境快速启动和测试

---

## 🚀 快速开始

### 方法一：首次启动（推荐）

1. **确保已安装 Go**
   - 下载地址：https://golang.org/dl/
   - 版本要求：Go 1.21 或更高版本
   - 验证安装：在命令行输入 `go version`

2. **启动服务**
   - 双击运行 `start_local.bat`
   - 或在命令行执行：
     ```bash
     cd task_server
     start_local.bat
     ```

3. **验证服务**
   - 浏览器访问：http://localhost:8080/health
   - 应该看到：`{"status":"ok","message":"Task Server is running"}`

### 方法二：快速启动（已构建后）

如果已经运行过方法一，后续可以快速启动：

1. 双击运行 `start_quick.bat`
2. 服务将在几秒内启动

## ⚙️ 配置说明

### 本地配置文件 (`configs/.env.local`)

```env
# 服务器配置
SERVER_PORT=8080              # 服务端口
SERVER_HOST=0.0.0.0          # 监听地址
GIN_MODE=debug               # 运行模式：debug/release

# 数据库配置 - 使用 SQLite（本地化方案）
DB_TYPE=sqlite               # 数据库类型
DB_PATH=./data/task_server.db # SQLite 数据库文件路径

# JWT 配置
JWT_SECRET=dev_jwt_secret_key_123456789  # JWT 密钥
JWT_EXPIRATION_HOURS=24     # Token 过期时间（小时）

# 日志配置
LOG_LEVEL=debug              # 日志级别：debug/info/warn/error
LOG_OUTPUT=stdout            # 日志输出：stdout/stderr/file
```

### 配置选项说明

| 配置项 | 说明 | 可选值 |
|--------|------|--------|
| `SERVER_PORT` | 服务端口 | 任意可用端口（如 8080、3000） |
| `GIN_MODE` | 运行模式 | `debug`（开发模式）、`release`（生产模式） |
| `DB_TYPE` | 数据库类型 | `sqlite`（推荐）、`postgres` |
| `LOG_LEVEL` | 日志级别 | `debug`、`info`、`warn`、`error` |

## 🔧 高级配置

### 使用 PostgreSQL 而非 SQLite

如果您已安装 PostgreSQL，可以修改配置：

1. 编辑 `configs/.env.local`，注释掉 SQLite 配置，取消注释 PostgreSQL 配置：

```env
# DB_TYPE=sqlite
# DB_PATH=./data/task_server.db

DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=your_password
DB_NAME=task_server
DB_SSLMODE=disable
```

2. 确保 PostgreSQL 服务正在运行
3. 创建数据库：
   ```sql
   CREATE DATABASE task_server;
   ```

4. 重新启动服务

### 启用 Redis 缓存（可选）

如果已安装 Redis，可以启用缓存功能：

1. 编辑 `configs/.env.local`，添加 Redis 配置：

```env
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=
REDIS_DB=0
```

2. 确保 Redis 服务正在运行
3. 重新启动服务

### 修改服务端口

如果 8080 端口被占用，可以修改端口：

1. 编辑 `configs/.env.local`：
   ```env
   SERVER_PORT=3000
   ```

2. 重新启动服务
3. 访问地址变为：http://localhost:3000

## ❗ 常见问题

### 问题 1：端口被占用

**错误信息**：`bind: address already in use`

**解决方案**：
1. 修改 `configs/.env.local` 中的 `SERVER_PORT`
2. 或者停止占用 8080 端口的进程：
   ```bash
   netstat -ano | findstr :8080
   taskkill /PID <进程ID> /F
   ```

### 问题 2：Go 环境未安装

**错误信息**：`'go' 不是内部或外部命令`

**解决方案**：
1. 下载安装 Go：https://golang.org/dl/
2. 重启命令行窗口
3. 验证安装：`go version`

### 问题 3：数据库文件创建失败

**错误信息**：`failed to open database`

**解决方案**：
1. 确保 `data` 目录存在
2. 检查是否有写入权限
3. 手动创建 `data` 目录：
   ```bash
   mkdir data
   ```

### 问题 4：依赖下载失败

**错误信息**：`go: module download failed`

**解决方案**：
1. 配置 Go 代理（国内用户）：
   ```bash
   go env -w GOPROXY=https://goproxy.cn,direct
   ```
2. 重新运行：
   ```bash
   go mod tidy
   ```

### 问题 5：构建失败

**错误信息**：`build failed`

**解决方案**：
1. 检查 Go 版本是否 ≥ 1.21
2. 清理缓存：
   ```bash
   go clean -cache
   ```
3. 重新构建：
   ```bash
   go build -o bin/task_server.exe cmd/server/main.go
   ```

## 📊 性能优化建议

### 开发环境

- 使用 SQLite（足够快速）
- 日志级别设为 `debug`
- 启用 Gin 的 `debug` 模式

### 生产环境

- 使用 PostgreSQL（更好的并发性能）
- 日志级别设为 `info` 或 `warn`
- 启用 Redis 缓存
- Gin 模式设为 `release`

## 🔄 与 Docker 方案对比

| 特性 | 本地化方案 | Docker 方案 |
|------|------------|-------------|
| 启动速度 | ⚡ 快（几秒） | 🐢 慢（几分钟） |
| 资源占用 | 💚 低 | 🟡 中等 |
| 依赖要求 | 仅需 Go | Docker + PostgreSQL + Redis |
| 配置复杂度 | 🟢 简单 | 🟡 中等 |
| 调试便利性 | 🟢 方便 | 🟡 一般 |
| 生产环境 | ⚠️ 不推荐 | ✅ 推荐 |
| 数据持久化 | 🟢 简单（文件） | 🟡 需要卷挂载 |
| 跨平台 | ✅ 支持 | ⚠️ 依赖 Docker |

**推荐使用场景**：
- **开发环境**：使用本地化方案（快速、简单）
- **生产环境**：使用 Docker 方案（稳定、可扩展）
