# 后台服务启动指南

## 前置条件检查

### ✅ 已确认
- Docker 已安装（版本 29.2.1）
- Docker Compose 已安装（版本 v5.0.2）
- 项目结构完整

### ⚠️ 需要操作
- Docker Desktop 需要先启动

## 启动方案

### 方案一：使用 Docker Compose（推荐）

#### 步骤 1：启动 Docker Desktop

1. 在 Windows 开始菜单中找到 "Docker Desktop"
2. 点击启动 Docker Desktop
3. 等待 Docker 完全启动（右下角 Docker 图标变为绿色并显示 "Docker Desktop is running"）

#### 步骤 2：验证 Docker 状态

打开命令行，执行：
```bash
docker ps
```

如果显示容器列表（可能为空），说明 Docker 已正常运行。

#### 步骤 3：进入项目目录

```bash
cd C:\ONEDRIVER\OneDrive\WORK\personal\GIT\CLAUDE2\task_server
```

#### 步骤 4：启动服务

```bash
docker-compose up -d
```

这个命令会：
- 🐘 启动 PostgreSQL 数据库（端口 5432）
- 📦 启动 Redis 缓存（端口 6379）
- 🚀 启动 Task Server 应用（端口 8080）

#### 步骤 5：查看服务状态

```bash
docker-compose ps
```

应该看到三个服务都在运行（Status 列显示 "Up"）

#### 步骤 6：查看日志

```bash
# 查看所有服务日志
docker-compose logs -f

# 只查看应用日志
docker-compose logs -f app
```

按 `Ctrl+C` 停止查看日志。

#### 步骤 7：验证服务

在浏览器中访问：
- **健康检查**: http://localhost:8080/health
- **API 基础路径**: http://localhost:8080/api/v1

使用 Postman 或 curl 测试：
```bash
# 健康检查
curl http://localhost:8080/health

# 用户注册示例
curl -X POST http://localhost:8080/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d "{\"username\":\"testuser\",\"email\":\"test@example.com\",\"password\":\"password123\",\"nickname\":\"测试用户\"}"

# 用户登录示例
curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d "{\"username\":\"testuser\",\"password\":\"password123\"}"
```

#### 步骤 8：停止服务

```bash
# 停止服务但保留容器
docker-compose stop

# 停止服务并删除容器
docker-compose down

# 停止服务并删除容器和数据卷
docker-compose down -v
```

### 方案二：本地开发运行（不使用 Docker）

#### 前置要求

- Go 1.21+ 已安装
- PostgreSQL 15+ 已安装并运行
- Redis 7+ 已安装并运行

#### 步骤 1：检查 Go 版本

```bash
go version
```

#### 步骤 2：安装依赖

```bash
cd C:\ONEDRIVER\OneDrive\WORK\personal\GIT\CLAUDE2\task_server
go mod download
```

#### 步骤 3：配置环境变量

复制配置文件：
```bash
copy configs\.env.example configs\.env
```

编辑 `configs\.env` 文件，配置数据库和 Redis 连接：
```env
SERVER_HOST=0.0.0.0
SERVER_PORT=8080

DB_HOST=localhost
DB_PORT=5432
DB_USER=taskuser
DB_PASSWORD=taskpass
DB_NAME=taskdb

REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_DB=0
REDIS_PASSWORD=

JWT_SECRET=your-secret-key-here-change-in-production

LOG_LEVEL=info
```

#### 步骤 4：创建数据库

连接到 PostgreSQL 并创建数据库：
```sql
-- 使用 psql 或其他 PostgreSQL 客户端
CREATE DATABASE taskdb;
CREATE USER taskuser WITH PASSWORD 'taskpass';
GRANT ALL PRIVILEGES ON DATABASE taskdb TO taskuser;
```

#### 步骤 5：运行服务

```bash
go run cmd/server/main.go
```

服务将在 http://localhost:8080 启动。

## 常见问题排查

### 问题 1：Docker Desktop 无法启动

**解决方案：**
1. 检查 Windows Subsystem for Linux (WSL) 是否启用
2. 以管理员身份运行 Docker Desktop
3. 重启计算机
4. 查看 Docker Desktop 日志

### 问题 2：端口已被占用

**错误信息：**
```
Bind for 0.0.0.0:5432 failed: port is already allocated
```

**解决方案：**
```bash
# 查找占用端口的进程
netstat -ano | findstr :5432

# 结束进程（使用上一步找到的 PID）
taskkill /PID <PID> /F
```

或者修改 `docker-compose.yml` 中的端口映射。

### 问题 3：数据库连接失败

**错误信息：**
```
failed to connect to database: connection refused
```

**解决方案：**
1. 等待 PostgreSQL 完全启动（可能需要 10-20 秒）
2. 检查 Docker 日志：`docker-compose logs postgres`
3. 验证数据库凭证是否正确

### 问题 4：服务启动失败

**解决方案：**
```bash
# 查看详细日志
docker-compose logs app

# 重新构建镜像
docker-compose build --no-cache

# 重启服务
docker-compose restart app
```

## 数据持久化

数据卷会持久化存储在 Docker 中：
- `postgres_data`: PostgreSQL 数据
- `redis_data`: Redis 数据

即使删除容器，数据也会保留。要完全清除数据：
```bash
docker-compose down -v
```

## 性能优化建议

### 1. 调整 Docker 资源限制

在 `docker-compose.yml` 中添加：
```yaml
services:
  app:
    # ... 其他配置
    deploy:
      resources:
        limits:
          cpus: '2'
          memory: 2G
        reservations:
          cpus: '1'
          memory: 1G
```

### 2. 数据库优化

在 PostgreSQL 容器中调整配置：
```yaml
postgres:
  # ... 其他配置
  command:
    - postgres
    - -c
    - max_connections=200
    - -c
    - shared_buffers=256MB
    - -c
    - effective_cache_size=1GB
```

### 3. Redis 优化

```yaml
redis:
  # ... 其他配置
  command: redis-server --maxmemory 512mb --maxmemory-policy allkeys-lru
```

## 安全建议

### 生产环境部署

1. **修改默认密码**：
   - 更改 `DB_PASSWORD` 和 `REDIS_PASSWORD`
   - 使用强密码

2. **设置 JWT_SECRET**：
   - 使用随机生成的强密钥
   - 不要在代码中硬编码

3. **限制网络访问**：
   - 不要将数据库端口暴露到公网
   - 使用防火墙规则

4. **启用 HTTPS**：
   - 配置反向代理（如 Nginx）
   - 使用 SSL 证书

5. **定期备份**：
   ```bash
   # 备份数据库
   docker exec task_postgres pg_dump -U taskuser taskdb > backup.sql
   
   # 恢复数据库
   docker exec -i task_postgres psql -U taskuser taskdb < backup.sql
   ```
