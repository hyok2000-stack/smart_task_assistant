### 数据表结构

#### 1. tasks 表（任务表）
```sql
CREATE TABLE tasks (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  content TEXT,
  status INTEGER DEFAULT 0,              -- 0:待处理, 1:进行中, 2:已完成, 3:已取消
  priority INTEGER DEFAULT 1,            -- 0:低, 1:中, 2:高
  start_time TEXT,
  due_time TEXT,
  completed_at TEXT,
  assignee TEXT,
  parent_id TEXT,                        -- 父任务ID（子任务）
  is_recurring INTEGER DEFAULT 0,        -- 是否周期任务
  recurring_rule TEXT,                   -- 周期规则: daily/weekly/monthly
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  tag_ids TEXT,                          -- JSON数组
  attachment_paths TEXT,                 -- JSON数组
  reminder_minutes INTEGER,              -- 提前提醒分钟数
  reminder_dismissed INTEGER DEFAULT 0,  -- 是否已关闭提醒
  reminder_voice_enabled INTEGER DEFAULT 0, -- 是否启用语音提醒
  reminder_voice_type TEXT DEFAULT 'neutral', -- 语音类型
  reminder_voice_style TEXT DEFAULT 'standard', -- 语音风格
  reminder_voice_speed TEXT DEFAULT 'normal',   -- 语音速度
  reminder_custom_voice_path TEXT        -- 自定义语音文件路径
)
```

**索引优化**:

- `idx_tasks_completed_at` - 按完成时间索引

**核心计算属性**:
```dart
/// 是否已完成
bool get isCompleted => status == TaskStatus.completed;

/// 是否已逾期
bool get isOverdue {
  if (dueTime == null || isCompleted) return false;
  return DateTime.now().isAfter(dueTime!);
}

/// 是否今天到期
bool get isDueToday {
  if (dueTime == null) return false;
  final now = DateTime.now();
  return dueTime!.year == now.year &&
      dueTime!.month == now.month &&
      dueTime!.day == now.day;
}

/// 是否明天到期
bool get isDueTomorrow {
  if (dueTime == null) return false;
  final tomorrow = DateTime.now().add(const Duration(days: 1));
  return dueTime!.year == tomorrow.year &&
      dueTime!.month == tomorrow.month &&
      dueTime!.day == tomorrow.day;
}
```

**关键方法**:
- `copyWith()`: 深度复制并修改对象
- `fromJson()`/`toJson()`: JSON序列化
- `dueTimeDescription`: 截止时间描述（"今天 18:00"、"明天 18:00"等）

### 2. AI服务模块（ai_service.dart）

#### 功能特性
1. **自然语言任务解析**: 从文本中提取任务信息
2. **AI优先级建议**: 基于任务信息生成优先级建议

##### 1. 本地规则引擎
```dart
ParsedTask _parseWithRules(String input)
```
**支持的时间表达**:
- 相对时间: "今天"、"明天"、"后天"、"X天后"、"X小时后"
- 周期时间: "下周几"、"本周几"、"周几"
- 具体日期: "3月15日"、"3月15号"
- 具体时间: "18:00"、"6点"、"下午3点"
- 时段: "上午"、"下午"、"晚上"、"中午"

**支持的其他信息**:
- 标签: `#工作`、`#个人`
- 负责人: `@张三`、`由张三负责`
- 优先级: "紧急"、"重要"、"不急"

**智能提醒推荐**:
```dart
int? _calculateRecommendedReminder(DateTime? dueTime, TaskPriority priority)
```
根据截止时间和优先级自动推荐提醒时间：
- 12小时内: 提前15分钟
- 24小时内: 提前1小时
- 3天内: 提前1天
- 本周内: 提前2天
- 下周及以后: 提前3天

##### 2. AI模型集成
支持OpenAI兼容API接口：
- 可配置API地址和密钥
- 支持多种AI模型
- 自动降级到本地规则引擎

##### 3. 智能优先级建议
```dart
Future<TaskPrioritySuggestion> generatePrioritySuggestion(List<Task> tasks)
```
**分析维度**:
