# 智能提醒推荐功能说明

## 功能概述

在快速创建任务时，系统会根据任务的**截止时间**和**优先级**，智能推荐合适的提醒时间。

## 推荐规则

### 基础规则（根据时间距离）

| 截止时间距离 | 基础提醒时间 |
|------------|-------------|
| 12小时内    | 提前15分钟   |
| 24小时内    | 提前1小时    |
| 3天内       | 提前1天      |
| 本周内（7天内） | 提前2天  |
| 下周及以后  | 提前3天      |

### 优先级调整

| 优先级 | 调整系数 | 示例 |
|--------|---------|------|
| 高优先级 | 1.5倍 | 基础15分钟 → 提前22分钟 |
| 中优先级 | 1.0倍 | 基础15分钟 → 提前15分钟 |
| 低优先级 | 0.8倍 | 基础15分钟 → 提前12分钟 |

## 使用示例

### 示例1：今天下午的任务
**输入：** "今天下午3点开会 #工作"

**识别结果：**
- 截止时间：今天 15:00
- 优先级：中优先级
- **推荐提醒：提前15分钟**（今天内任务，基础15分钟）

### 示例2：明天的高优先级任务
**输入：** "明天紧急提交报告"

**识别结果：**
- 截止时间：明天 18:00
- 优先级：高优先级
- **推荐提醒：提前90分钟**（明天任务基础1小时，高优先级×1.5=90分钟）

### 示例3：下周的会议
**输入：** "下周三下午参加培训"

**识别结果：**
- 截止时间：下周三 18:00
- 优先级：中优先级
- **推荐提醒：提前2天**（下周任务，基础2天）

### 示例4：今天上午的低优先级任务
**输入：** "今天上午整理文件，不急"

**识别结果：**
- 截止时间：今天 09:00
- 优先级：低优先级
- **推荐提醒：提前12分钟**（今天内任务基础15分钟，低优先级×0.8=12分钟）

## 可选提醒时间

系统提供以下预设选项：
- 不提醒
- 提前10分钟
- 提前15分钟 ✨（新增）
- 提前30分钟
- 提前1小时
- 提前1天 ✨（新增）
- 提前2天 ✨（新增）
- 提前3天 ✨（新增）

## UI特性

1. **推荐项高亮显示**：推荐的提醒时间会以主色调显示，并带有"✨推荐"标签
2. **星形图标**：推荐的选项会显示星形图标 `auto_awesome`
3. **边框加粗**：推荐的选项边框更粗，更容易识别
4. **自动应用**：系统会自动选择推荐的提醒时间，用户可以手动修改

## 技术实现

### 1. 数据模型

```dart
class ParsedTask {
  final String title;
  final DateTime? dueTime;
  final TaskPriority priority;
  final int? recommendedReminderMinutes; // 新增：推荐的提醒分钟数
  // ...
}
```

### 2. 推荐算法

```dart
int? _calculateRecommendedReminder(DateTime? dueTime, TaskPriority priority) {
  if (dueTime == null) return null;
  
  final hoursUntilDue = dueTime.difference(DateTime.now()).inHours;
  if (hoursUntilDue <= 0) return null;
  
  int baseReminderMinutes;
  
  // 根据时间距离计算基础提醒时间
  if (hoursUntilDue < 12) {
    baseReminderMinutes = 15;
  } else if (hoursUntilDue < 24) {
    baseReminderMinutes = 60;
  } else if (hoursUntilDue < 72) {
    baseReminderMinutes = 24 * 60;
  } else if (hoursUntilDue < 168) {
    baseReminderMinutes = 48 * 60;
  } else {
    baseReminderMinutes = 72 * 60;
  }
  
  // 根据优先级调整
  switch (priority) {
    case TaskPriority.high:
      return (baseReminderMinutes * 1.5).toInt();
    case TaskPriority.low:
      return (baseReminderMinutes * 0.8).toInt();
    default:
      return baseReminderMinutes;
  }
}
```

### 3. UI应用

```dart
// 在解析完成后自动应用推荐值
if (result.recommendedReminderMinutes != null) {
  _selectedReminderMinutes = result.recommendedReminderMinutes;
  _showCustomReminder = !_isInReminderOptions(_selectedReminderMinutes);
}

// 在UI中高亮显示推荐项
final isRecommended = minutes != null &&
    minutes == _parsedTask?.recommendedReminderMinutes &&
    !_showCustomReminder;

final chipColor = isRecommended ? AppTheme.primaryColor : AppTheme.warningColor;
```

## 使用流程

1. 打开快速创建任务对话框
2. 输入任务内容（包含时间和优先级信息）
3. 系统自动解析并推荐提醒时间
4. 查看推荐选项（会以主色调高亮显示）
5. 可以接受推荐，或选择其他预设选项，或自定义时间
6. 创建任务

## 注意事项

- 如果推荐的提醒时间不在预设选项中，会自动显示"自定义"输入框
- 推荐的提醒时间仅作为建议，用户可以自由修改
- 如果任务没有截止时间，不会提供推荐
- 如果截止时间已经过去，不会提供推荐
