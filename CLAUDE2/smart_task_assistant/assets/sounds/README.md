# 音频文件说明

本目录用于存放应用内的提示音文件。

## 需要的文件

- `notification.mp3` - 任务提醒提示音

## 如何添加提示音

1. 准备一个简短的提示音文件（建议时长：1-2秒）
2. 将文件命名为 `notification.mp3`
3. 将文件放置在当前目录（`assets/sounds/`）下
4. 重新编译应用

## 提示音资源

你可以从以下来源获取提示音：

- 系统自带的提示音
- 免费的音效网站（如 Freesound.org）
- 在线提示音生成器

## 注意事项

- 文件大小建议小于 100KB
- 使用 MP3 格式，兼容性最好
- 音量适中，不要过于刺耳
- 提示音应清晰且易于识别
