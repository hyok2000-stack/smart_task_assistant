# 后台服务本地启动快速指南

## 🚀 三步启动

### 第一步：安装 Go
下载并安装 Go：https://golang.org/dl/

### 第二步：首次启动
双击运行 `task_server/start_local.bat`

### 第三步：验证服务
浏览器访问：http://localhost:8080/health

---

## ✅ 启动成功标志

看到以下内容即表示成功：
```json
{
  "status": "ok",
  "message": "Task Server is running"
}
```

---

## 📝 后续启动

每次开发时，直接双击运行 `task_server/start_quick.bat` 即可快速启动。

## 🎯 核心优势

- ✅ **零依赖**：无需 Docker、PostgreSQL、Redis
- ✅ **快速启动**：几秒钟即可启动
- ✅ **简单配置**：使用 SQLite 数据库
- ✅ **易于调试**：直接运行，日志清晰

## ❗ 常见问题

**端口被占用？**
- 修改 `task_server/configs/.env.local` 中的 `SERVER_PORT` 为其他端口

**Go 未安装？**
- 下载安装 Go：https://golang.org/dl/

**依赖下载失败？**
- 执行：`go env -w GOPROXY=https://goproxy.cn,direct`
