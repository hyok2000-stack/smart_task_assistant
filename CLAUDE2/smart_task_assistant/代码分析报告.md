#### 2.1.1 Task 模型 (task.dart)
**职责**: 定义任务的数据结构

**核心字段**:
```dart
class Task {
  final String id;                    // 任务 ID
  final String title;                 // 任务标题
  final String? content;              // 任务详情
  final DateTime? dueTime;            // 截止时间
  final TaskPriority priority;        // 优先级 (high/medium/low)
  final TaskStatus status;            // 状态 (pending/inProgress/completed)
  final List<String> tagIds;          // 标签 ID 列表
  final int? reminderMinutes;         // 提醒时间（分钟）
  final bool isRecurring;             // 是否周期任务
  final String? recurringRule;        // 周期规则
  final DateTime createdAt;           // 创建时间
  final DateTime updatedAt;           // 更新时间
  final DateTime? completedAt;        // 完成时间
}
```

**设计亮点**:
- 使用不可变对象模式 (`final` 字段)

- 计算属性 `isOverdue` 判断是否逾期

### 2.3 服务层 (Services)

#### 2.3.1 AIService (ai_service.dart)
**职责**: 提供 AI 智能识别和解析功能

**核心功能**:

1. **AI 配置管理**
```dart
class AIConfig {
  String provider;                    // 提供商

  String baseUrl;                     // API 地址
  String model;                       // 模型名称
```

2. **任务解析**
```dart
// AI 解析（优先）
Future<ParsedTask?> parseTask(String input);

// 本地规则解析（回退）
ParsedTask parseTaskLocal(String input);
```

3. **本地规则引擎**
- 支持自然语言时间识别:
  - 相对时间: 今天、明天、后天、本周、下周
  - 星期几: 周一至周日
  - 具体日期: X月X日
  - 具体时间: HH:mm、X点X分
  - 时段: 上午、下午、晚上
  - 延时: X天后、X小时后

- 支持优先级识别:
  - 高优先级: 紧急、重要、急、尽快
  - 低优先级: 不急、有空、闲暇

- 支持标签提取: #标签名
- 支持负责人提取: @某人、由XX负责

4. **AI 服务支持**
- OpenAI 兼容 API
- 本地 Ollama
- DeepSeek、通义千问、智谱AI、Kimi 等

5. **自动回退机制**
- AI 解析失败时自动切换到本地规则
- 连接失败时自动禁用 AI 并提示用户
- 保存当前模型配置用于故障排查

**设计亮点**:
- 双模式设计（AI + 本地规则）
- 完善的错误处理和回退机制
- 支持多种 AI 服务提供商
- 测试连接功能确保配置正确

**可改进点**:
- 建议添加更多自然语言模板
- 建议支持自定义规则

```dart
@override
void initState() {
  super.initState();
  
  // 如果有初始内容，自动解析
  if (widget.initialContent != null && widget.initialContent!.isNotEmpty) {
    _controller.text = widget.initialContent!;
    WidgetsBinding.instance.addPostFrameCallback((_) {
      _parseInputAuto(widget.initialContent!);
    });
  }
}

/// 自动解析输入（优先使用 AI，失败回退到本地规则）
Future<void> _parseInputAuto(String input) async {
  setState(() => _isAILoading = true);
  
  try {
    // 加载 AI 配置
    await _aiService.loadConfig();
    
    // 尝试使用 AI 解析
    final result = await _aiService.parseTask(input);
    
    if (result != null && mounted) {
      setState(() {
        _parsedTask = result;
        _selectedPriority = result.priority;
        _selectedDueTime = result.dueTime;
        _selectedTags = result.tags;
      });
    } else {
      // AI 解析失败，回退到本地规则
      _parseInputLocal(input);
    }
  } catch (e) {
    debugPrint('AI解析失败，使用本地规则: $e');
    _parseInputLocal(input);
  } finally {
    setState(() => _isAILoading = false);
  }
}
```

## 三、技术架构分析

### 3.1 架构模式
采用 **MVVM (Model-View-ViewModel)** 模式:
- **Model**: 数据模型 (Task, Tag)
- **View**: 页面和组件 (Screens, Widgets)
- **ViewModel**: 状态管理 (Providers)

### 3.2 状态管理
使用 **Provider** 模式:
```dart
ChangeNotifierProvider(
  create: (_) => TaskProvider(),
  child: MyApp(),
)

// 使用
context.watch<TaskProvider>()
context.read<TaskProvider>()
```

### 3.3 数据流
```
用户操作 → View → Provider → Database/Service → Provider → View 更新
```

### 3.4 平台适配
使用条件导入实现平台适配:
```dart
// storage_service.dart
import 'storage_service_stub.dart'
    if (dart.library.io) 'storage_service_native.dart'
    if (dart.library.html) 'storage_service_web.dart';
```
