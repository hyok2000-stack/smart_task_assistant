# 智能任务助手 - 项目代码分析报告

## 一、项目概述

### 1.1 基本信息
- **项目名称**: 智能任务助手 (Smart Task Assistant)
- **当前版本**: v1.2.8 (build 32)
- **开发框架**: Flutter 3.2.0+
- **编程语言**: Dart
- **状态管理**: Provider
- **数据库**: SQLite (sqflite)

### 1.2 项目定位
基于AI的智能任务管理工具，支持自然语言解析、智能提醒、任务统计等功能。

## 三、核心模块分析

### 3.1 数据模型层 (lib/models/)

#### Task (任务模型)
```dart
核心属性：
- id: 唯一标识
- title: 任务标题
- content: 任务详情
- status: 状态 (pending/inProgress/completed/cancelled)
- priority: 优先级 (low/medium/high)
- startTime/dueTime: 开始/截止时间
- completedAt: 完成时间
- tagIds: 关联标签ID列表
- attachmentPaths: 附件路径列表
- reminderMinutes: 提醒分钟数
- reminderDismissed: 是否关闭提醒
- isRecurring: 是否周期任务
- recurringRule: 周期规则 (daily/weekly/monthly)
```

**特点**:
- 完整的任务生命周期管理
- 支持周期任务
- 灵活的标签系统
- 提醒机制
- 完善的JSON序列化

#### Tag (标签模型)
```dart
核心属性：
- id: 唯一标识
- name: 标签名称
- color: 十六进制颜色值
- icon: 图标名称
- sortOrder: 排序顺序
- isDefault: 是否为默认标签
```

**特点**:
- 预设4个默认标签（工作/个人/紧急/学习）
- 支持自定义颜色和图标
- 可排序

- **API Key**: 4d8fb5b93d4af21d66a2948710284366 (公开的免费API密钥)

## 四、核心功能实现

### 4.1 自然语言任务解析
**输入示例**: "明天下午3点开会 #工作 @张三 紧急"

**解析过程**:
1. 提取标签: #工作
2. 提取负责人: @张三
3. 识别优先级: 紧急 → high
4. 识别时间: 明天下午3点 → 具体DateTime
5. 提取标题: 开会

**输出结果**:
```dart
ParsedTask(
  title: "开会",
  dueTime: 2026-03-22 15:00:00,
  priority: TaskPriority.high,
  assignee: "张三",
  tags: ["工作"]
)
```

### 4.2 提醒机制
**流程**:
```
1. 定时检查（每10秒）
2. 判断是否需要提醒
   - 检查提醒时间
   - 检查上次提醒时间
   - 检查稍后提醒设置
3. 播放声音+振动
4. 显示提醒弹窗
5. 用户选择操作
   - 稍后提醒
   - 修改时间
   - 关闭提醒
   - 标记完成
```

### 4.3 周期任务
**规则**:
- daily: 每天重复
- weekly: 每周重复
- monthly: 每月重复

**触发时机**: 任务被标记为完成时

**新任务创建**:
- 复制原任务属性
- 生成新ID
- 重置状态为pending
- 根据规则计算新截止时间
- 清除完成时间

### 4.4 数据持久化
**存储方式**:
- SQLite: 主数据库
- SharedPreferences: 配置和AI设置
- 文件系统: 数据导出

**数据备份**:
- Web端: 自动备份到IndexedDB
- 移动端: 支持导出JSON文件

**迁移机制**:
- 数据库版本管理
- 自动升级脚本
- 向后兼容
