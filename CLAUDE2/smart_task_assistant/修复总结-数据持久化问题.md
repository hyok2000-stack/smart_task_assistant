# 数据持久化问题修复总结

## 问题描述

用户反馈：应用重启后（从最近应用中划掉再打开），之前添加的任务数据不显示，只有默认标签。

## 问题根源分析

### 核心问题
应用重启后，静态单例 `DatabaseHelper._database` 可能仍然持有旧的、已失效的数据库连接引用。虽然代码有连接检测逻辑，但在以下场景下可能失效：

1. **应用被完全杀死**：用户从最近应用中划掉应用，进程被终止
2. **静态变量残留**：重启后，静态变量可能保留了旧引用
3. **连接检测不完善**：简单的查询可能无法完全检测连接状态

### 数据流程回顾

```
应用启动 → main.dart → TaskProvider.loadData() → NativeStorageService.init() 
→ DatabaseHelper.database → SQLite查询
```

当 `DatabaseHelper.database` 返回已失效的连接时，后续所有数据库操作都会失败，导致：
- `getAllTasks()` 返回空列表
- UI显示空数据
- 用户误以为数据丢失

## 修复方案

### 1. 增强应用生命周期管理

**文件：`lib/main.dart`**

- 添加 `DatabaseHelper` import
- 在 `AppLifecycleState.resumed` 时强制重置数据库连接并重新加载数据
- 在 `AppLifecycleState.detached` 时重置所有单例连接
- 新增 `_reloadDataWithReset()` 方法：强制重置连接后重新加载
- 新增 `_resetAllConnections()` 方法：清理所有单例连接

### 2. 添加数据库连接重置方法

**文件：`lib/providers/task_provider.dart`**

- 添加 `DatabaseHelper` import
- 新增 `resetDatabaseConnection()` 方法：
  - 检测是否为原生平台（Web平台无需重置）
  - 调用 `DatabaseHelper.resetConnection()`
  - 重新初始化存储服务

### 3. 增强数据库连接重置逻辑

**文件：`lib/database/database_helper.dart`**

- 改进 `resetConnection()` 方法：
  - 添加详细的调试日志
  - 安全关闭现有连接（捕获关闭失败异常）
  - 清空数据库引用 `_database = null`
  - 确保即使出错也能清空引用

## 修复效果

### 修复前
```
用户添加任务 → 数据写入SQLite ✅
用户关闭应用 → 进程终止 ❌
用户重新打开应用 → 数据库连接失效 ❌
→ getAllTasks() 返回空列表
→ UI显示空数据
```

### 修复后
```
用户添加任务 → 数据写入SQLite ✅
用户关闭应用 → 进程终止 ❌
用户重新打开应用 → AppLifecycleState.resumed ✅
→ resetDatabaseConnection() 重置连接 ✅
→ loadData() 重新加载数据 ✅
→ UI正确显示所有任务 ✅
```

## 关键改进点

1. **主动检测和重置**：不再是被动等待查询失败，而是在应用恢复时主动重置
2. **生命周期感知**：利用 `WidgetsBindingObserver` 监听应用状态变化
3. **详细日志**：每个关键步骤都有调试日志，便于问题追踪
4. **异常处理**：所有重置操作都有异常捕获，确保不会崩溃
5. **兼容性**：Web平台会自动跳过重置逻辑

## 技术细节

### 数据库连接状态检测

```dart
if (_database != null) {
  try {
    await _database!.query('sqlite_master', limit: 1);
    debugPrint('数据库连接正常');
    return _database!;
  } catch (e) {
    // 数据库已关闭，需要重新初始化
    debugPrint('⚠️ 数据库连接已关闭或无效，正在重新初始化: $e');
    _database = null;
  }
}
```

这个检测逻辑会在每次访问数据库时执行，确保连接有效。

### 单例模式的应用

`DatabaseHelper` 使用单例模式确保全局只有一个数据库连接实例：

```dart
static final DatabaseHelper _instance = DatabaseHelper._internal();
static Database? _database;

factory DatabaseHelper() => _instance;
```

`resetConnection()` 方法会清空静态的 `_database` 引用，强制下次访问时重新建立连接。

### 应用生命周期监听

通过 `WidgetsBindingObserver` 监听应用状态：

```dart
class _MyAppState extends State<MyApp> with WidgetsBindingObserver {
  @override
  void didChangeAppLifecycleState(AppLifecycleState state) {
    switch (state) {
      case AppLifecycleState.resumed:
        _reloadDataWithReset();
        break;
      case AppLifecycleState.detached:
        _resetAllConnections();
        break;
      // ... 其他状态
    }
  }
}
```
