## 识别的问题

### 1. 重复计算问题
**问题描述：**
- `_recalculateTodayTasks` 和 `_overdueTasks` 计算逻辑在多个地方重复
- 每次数据变更都重新计算统计数据，缺乏缓存机制
- 筛选逻辑散落在 Provider 的各个方法中

**影响：**
- 性能低下，尤其是在任务数量较多时
- 代码重复，难以维护
- UI 响应速度慢

### 2. 代码重复问题
**问题描述：**
- 多处有相似的任务列表过滤逻辑
- 统计计算代码重复
- 筛选条件处理逻辑分散

**影响：**
- 代码冗余
- 维护困难
- 容易出现不一致

### 3. 可扩展性差
**问题描述：**
- 添加新的筛选条件需要修改多处代码
- 缺乏统一的筛选接口
- 排序逻辑不统一

**影响：**
- 新功能开发困难
- 代码耦合度高
- 测试复杂

## 优化方案

### 1. 创建 TaskFilter 工具类

**文件：** `lib/utils/task_filter.dart`

**功能：**
- 统一处理任务的各种筛选和分类逻辑
- 提供静态方法，无需实例化
- 支持多种筛选条件组合

**主要方法：**

```dart
// 获取今日任务
static List<Task> getTodayTasks(List<Task> tasks)

// 获取逾期任务
static List<Task> getOverdueTasks(List<Task> tasks)

// 按状态筛选
static List<Task> filterByStatus(List<Task> tasks, TaskStatus? status)

// 按优先级筛选
static List<Task> filterByPriority(List<Task> tasks, TaskPriority? priority)

// 按标签筛选
static List<Task> filterByTag(List<Task> tasks, String? tagId)

// 按关键词搜索
static List<Task> searchByKeyword(List<Task> tasks, String keyword)

// 组合筛选
static List<Task> filterTasks({
  required List<Task> tasks,
  TaskStatus? status,
  TaskPriority? priority,
  String? tagId,
  String? keyword,
})

// 获取统计数据
static Map<String, int> getTaskStats(List<Task> tasks)

// 排序方法
static List<Task> sortByPriority(List<Task> tasks, {bool descending = true})
static List<Task> sortByDueTime(List<Task> tasks, {bool ascending = true})

```

**优势：**
- 代码集中管理，易于维护
- 可复用性强
- 易于测试
- 扩展性好

### 2. 创建 TaskProviderOptimized 优化版

**文件：** `lib/providers/task_provider_optimized.dart`

**主要优化：**

#### 2.1 添加缓存机制

```dart
/// 任务缓存数据类
class TaskCache {
  final DateTime timestamp;
  final List<Task> todayTasks;
  final List<Task> overdueTasks;
  final Map<String, int> stats;

  /// 检查缓存是否有效（1秒内有效）
  bool get isValid {
    final now = DateTime.now();
    return now.difference(timestamp).inMilliseconds < 1000;
  }
}
```

**缓存策略：**
- 缓存今日任务、逾期任务和统计数据
- 缓存有效期：1秒
- 数据变更时自动清除缓存

#### 2.2 优化 Getter 方法

```dart
/// 今日任务（带缓存）
List<Task> get todayTasks {
  if (_cache?.isValid == true) {
    return _cache!.todayTasks;
  }
  return TaskFilter.getTodayTasks(_tasks);
}

/// 逾期任务（带缓存）
List<Task> get overdueTasks {
  if (_cache?.isValid == true) {
    return _cache!.overdueTasks;
  }
  return TaskFilter.getOverdueTasks(_tasks);
}

/// 统计数据（带缓存）
Map<String, int> get stats {
  if (_cache?.isValid == true) {
    return _cache!.stats;
  }
  return TaskFilter.getTaskStats(_tasks);
}
```

#### 2.3 统一筛选逻辑

```dart
/// 筛选后的任务列表（使用统一筛选方法）
List<Task> get filteredTasks {
  return TaskFilter.filterTasks(
    tasks: _tasks,
    status: _filterStatus,
    priority: _filterPriority,
    tagId: _filterTagId,
    keyword: _searchQuery,
  );
}
```

#### 2.4 简化数据更新逻辑

```dart
/// 更新缓存
void _updateCache() {
  _cache = TaskCache(
    timestamp: DateTime.now(),
    todayTasks: TaskFilter.getTodayTasks(_tasks),
    overdueTasks: TaskFilter.getOverdueTasks(_tasks),
    stats: TaskFilter.getTaskStats(_tasks),
  );
}

/// 清除缓存
void _clearCache() {
  _cache = null;
}
```
